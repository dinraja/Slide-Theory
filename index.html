How to play

Goal: put the tiles in order from 1 to 15, reading left to right and top to bottom. The empty space ends up in the bottom-right corner.

1

Slide tiles

Click a tile next to the empty space (or press an arrow key) and it slides in. Only tiles touching the empty space can move.

2

Work row by row

Finish the top row (1, 2, 3, 4) first, then the second row (5, 6, 7, 8). Once a row is done, leave it alone.

3

The last tile of a row

For tile 4, put 3 in the top-right corner and 4 directly under it, with the empty space just left of the 3. Then slide 3 left and 4 up.

4

Finish column by column

Do the bottom two rows one column at a time (9 and 13 first, then 10 and 14) using the same trick. Turn the last few tiles around the empty space like a small roundabout.

5

Count your moves

Fewer moves means a better score. Hint and AI Solve are great for learning, but a game that used them doesn’t count towards your best score.

How the AI solver thinks

The AI uses IDA* (Iterative Deepening A*), which always finds a shortest solution. The puzzle has about 10 trillion possible positions, so it can’t try them all and has to search smartly.

1

Guess the distance

It estimates the moves left: the Manhattan distance (rows and columns every tile is from home), plus 2 for each pair of tiles blocking each other in their goal row or column. The guess is never too high, which keeps the answer the shortest.

2

Set a limit

It explores one path at a time, but drops any path where moves made so far plus estimated moves left goes over the limit.

3

Raise the limit and repeat

If no solution fits, it raises the limit to the smallest value that was cut off and searches again, until the solution appears.

4

Light and smooth

Following a single path needs very little memory, and the search runs in the background so the page doesn’t freeze. Hint uses the same solver.
